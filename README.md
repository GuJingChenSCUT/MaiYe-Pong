# 买嘢帮 MVP

这是面向香港消费者的受控购物代理开发版。本次以用户提供的 stop-ui-r2 工程为基础，修复 Windows 实际运行问题、存储故障处理和模型执行边界，提供可启动的本地网页。正式产品名为「買嘢幫」。

**当前可验收的是本地研究、比较、确认入队、停止和恢复。商品为明确标示的合成数据，付款为 LocalPSP；没有实际商户成交或官方钱包回执。停点一仍未通过。** 用户表示已有获准商户及 PSP 沙盒账号，供应商名称、开放权限和接口资料仍待核验。

## 在 Windows 启动

需要 Python 3.12 或更新版本。在本目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup-local.ps1
powershell -ExecutionPolicy Bypass -File scripts\start-local.ps1 -Offline
```

浏览器入口为 `http://127.0.0.1:8765/`。本机窗口显示 buyer、merchant、operator 三个开发存取码，复制 buyer 码登录。窗口关闭后可运行 `scripts\show-access.ps1` 再次查看。三个身份由服务器绑定，不能在网页改角色。登录码、会话与数据库只保存在忽略提交的 `local_state`，交付 ZIP 不含它们。开发身份不适合公网使用。

启动器沿用同一数据库和已有服务。若端口中的服务模式不符会报错，不会静默将在线服务当成离线服务。结束服务可先核对 `local_state\server.pid` 中的进程；保留数据库及同目录 WAL/SHM 文件，不要只复制主数据库。

## 体验一次完整的本地委托

1. 登录后先看到需求输入框。展开「演練與模型設定」，点击「填入合成商品演練」（会明确切至本地模式，不调用模型）。展开「補充預算與購買條件」，先去掉预算提交，再补答 HK$100，验证只补必要资料。
2. 选择「较早送达」，查看两家报价、完整现金支出、配送和退货。系统选择符合硬条件的方案，再按用户偏好排序。
3. 核对并明确确认，看到同一快照对应的本地操作入队。入队不表示已付款。
4. 点击「停止这次委托」，明确提交后查看后端结果。刷新仍保留状态。Esc 和取消不会停止任务。
5. 在已停止的任务选择「按这次需求再委托」。规格、数量、预算和偏好带入新表单；旧送达期限清空，报价和付款授权重新生成。付款未决或批准请求未返回时禁止此操作。
6. 用「运费上升」「两家都无法供货」「恶意商品文案」演练重新比较和规则停止。没有商户事实的真实商品不能被静默替换成演练肥皂。

网页目前没有派发付款端点。LocalPSP 成功、UNKNOWN 原单恢复及拒绝交易由交易内核测试验证，不能称为网页已完成真实支付。真实订单与付款仍分别记录。

## DeepSeek 配置与在线验收

2026-10-04 更新：真实 `deepseek-flash` 已通过正常需求、缺资料澄清、运费变化和恶意商品文案四类行为验收。网页 → 后台 worker → 真实模型 → 持久化方案 → 停止 → 刷新恢复的联调也已通过。商品仍是合成目录，没有商户或 PSP 交易。

运行 `scripts\configure-deepseek.ps1` 会打开掩码输入窗口。API Key 使用 Windows 当前用户 DPAPI 加密，保存在 `%LOCALAPPDATA%\MaiYeBang\deepseek.key.dpapi`，不写入源码、网页、对话或交付包。同一 Windows 用户下运行的其他程序仍可解密；这是本地开发配置，不是生产密钥管理服务。

已修复 PowerShell 加密模块解析错误，保存失败会显示受控错误信息。若你已有专用密钥文件，可运行 `checkpoint\engineering\.venv\Scripts\python.exe -X utf8 scripts\import-secret-file.py "完整文件路径"`。导入器仅接受一条可识别的 key，不输出文件内容、不调用模型、不删除原文件。不要把密钥文件放入工程或交付包。

原生窗口未显示时，可运行 `checkpoint\engineering\.venv\Scripts\python.exe -X utf8 scripts\secret-input.py`，然后打开 `http://127.0.0.1:8769/` 使用本机密码框。页面只接受本机同源请求，检查 CSRF，没有读取密钥接口，不会调用模型。输入成功后清空并隐藏表单；配置服务可在输入完成后关闭。

模型 ID 为 `deepseek-flash`。应用使用官方 Chat Completions 工具回环；模型提出工具调用，应用验证并执行。不能给模型付款、审批、数据库或密钥读取权限。请求与返回型号都记录；未确认的型号映射不会自动算验收通过。

配置完成后运行四类收费在线验收：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\test-live.ps1 -AllowProviderCharge
```

每次调用 `run_task_v1` 的两个角色共享最多 16 次生成请求、32,768 预留输出 token、512 KiB 累计请求体和 180 秒期限。四场景最多 64 次生成请求；这不是货币预算，也不是任务全部重试的终身限额。网络 socket 超时不等于严格墙钟中断；迟到结果不能继续执行工具。真实使用须核对账户费用与账单。测试产物采用新文件名，保留失败证据。

在线网页服务启动时读取密钥；已运行的离线进程不会自动获得新密钥。保存后使用新的端口启动：`scripts\start-local.ps1 -Port 8766`，或明确重启原服务。`-Offline` 不读取密钥。移除密钥可运行 `scripts\configure-deepseek.ps1 -Remove`。

## 沙盒与公网的下一步

首条接入保持「两家比较、一家成交、HKD、一个 PSP」：获准商户固定报价与建单 → 绑定订单的支付会话 → 官方钱包由用户确认 → 后端验签并核对订单、收款方、金额和币种 → 查询原交易与异常恢复。浏览器回跳不证明成功，UNKNOWN 不另建付款。

请补充 PSP 名称、准确钱包名称、商户接口与沙盒文档；秘密材料使用单独本机输入通道。Antom/AlipayHK、WeChat Pay HK、Octopus 的开放文档不代表团队权限；HKTVmall 商户 MMS 或淘宝商品查询权限也不等于通用消费者下单权限。当前来源核验见 `verification\research_20261003.json`。

公网版本需要真实身份、HTTPS、可靠持久存储、备份恢复、监控、授权来源及商户/PSP 回调验证。本地 HTTP 服务器只绑定回环地址，不能直接部署为公网支付服务。现有根目录 TypeScript/Convex 接入准备代码保留在工作区；它不包含当前交易闭环，本轮没有用它替换 Python 内核。Charming 或展示站托管也不能替代交易内核的原子性与恢复验证。HKT/The Club 仍为候选合作方。
